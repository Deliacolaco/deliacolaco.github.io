# Portfolio

This repository contains the source code for my personal portfolio website, hosted with GitHub Pages at [https://deliacolaco.github.io](https://deliacolaco.github.io).

The site presents my work across business analytics, dashboard development, data visualisation, reporting, and decision support. It is designed as a recruiter-friendly portfolio that brings together my projects, technical skills, education, experience, resume, GitHub, and LinkedIn in one place.

## About

I am Delia Colaco, a Business Analytics graduate from Macquarie University with experience across data analysis, dashboard development, business development, market research, and operational reporting.

My portfolio highlights selected analytics projects built using tools such as Python, SQL, Qlik Sense, Tableau, Excel, and GitHub. The focus is on showing how I turn data into clear visual outputs, practical insights, and business recommendations.

## Featured Projects

- **Gym Member Segmentation & Marketing Strategy**  
  Python clustering project using K-Means++ and Agglomerative Clustering to segment 2,000 gym members into actionable customer profiles.

- **Student Retention Analytics, Macquarie University**  
  Group project for BUSA8031 where I designed and built Dashboard 2 in Qlik Sense for University Executives to monitor retention, equity outcomes, and faculty performance.

- **More Projects Coming Soon**  
  Additional analytics projects will be added as the portfolio develops.

## Features

- Responsive portfolio website built with Jekyll and GitHub Pages
